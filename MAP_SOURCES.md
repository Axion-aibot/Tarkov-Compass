# Tarkov Compass · RE3MR map sources / attribution

This build uses RE3MR community map artwork as the local visual base layer.

Primary source: https://reemr.se/

Main maps bundled locally:
- Customs
- Factory
- Ground Zero
- Icebreaker
- Interchange
- The Labyrinth
- Lighthouse
- Reserve
- Shoreline
- Streets of Tarkov
- Terminal
- Woods

RE3MR detail/reference maps bundled locally:
- Customs Dorms
- Reserve Tunnels
- Shoreline Resort
- Streets cache reference
- Streets LexOs reference
- Transit overview
- Woods Train Depot

The RE3MR homepage describes the maps as free fan art and lists the main and sub-location map sets. It states a Creative Commons Attribution-NonCommercial-ShareAlike license for the map project. Individual map pages may state a more specific version/license; for example Ground Zero's page identifies its current map as CC BY-NC-SA 2.0, while the current Customs, Factory, Icebreaker, Shoreline, Streets and Woods pages state CC BY-NC-SA 4.0.

Some local image copies were obtained through public mirrors that credit RE3MR; the artwork attribution remains RE3MR. This project is not affiliated with RE3MR or Battlestate Games and is intended for personal, non-commercial offline/practice use.

POI coordinates, quest coordinates and live data are separate from the RE3MR artwork. When an internet connection is available, the tracker can refresh structured map/quest data through its configured community data sources. Local starter pins are included so pin filters are functional before a refresh.
